# Ping Tray v2

Дважды щёлкните `start.cmd`. Приложение запустится в трее Windows и начнёт пинговать `2ip.ru`. При первом запуске `uv` подготовит локальное окружение проекта с Python 3.12. Чтобы проверить другой адрес, запустите из PowerShell в этой папке:

```powershell
.\start.cmd 1.1.1.1
```

Для запуска при входе в Windows дважды щёлкните `enable_autostart.cmd`. Чтобы отключить автозапуск, запустите `disable_autostart.cmd`. Скрипты управляют ярлыком `Ping Tray.lnk` в автозагрузке текущего пользователя.

После каждого успешного ответа зелёный диск расширяется из центра всё время до следующего запроса. Одновременно прозрачность зелёного растёт от 0% до 100%, открывая тёмную основу. К моменту отправки следующего запроса зелёный достигает полного размера и исчезает. Пока ответа нет, из центра растёт красный диск. Через секунду он заполняет круг и остаётся таким до успешного ответа, в том числе при повторных попытках.

Шаг анимации — 30 мс. Размер и прозрачность рассчитываются по часам, поэтому пропуск кадра в Windows не замедляет анимацию. Обычно запросы отправляются раз в секунду. Приложение ждёт ответ до двух секунд. Если успешный ответ пришёл позже секунды, следующий запрос отправляется через секунду после ответа, чтобы успела пройти зелёная анимация.

Наведите указатель на значок, чтобы увидеть адрес и задержку либо состояние запроса. Для завершения щёлкните значок правой кнопкой мыши и выберите **Выход**.
